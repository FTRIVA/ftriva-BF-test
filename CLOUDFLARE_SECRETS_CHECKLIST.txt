FTRIVA BLACK FRIDAY WEBSITE — CONFIGURATION CHECKLIST

Required Cloudflare Worker secrets/variables:
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY (secret; never put in GitHub or share in chat)
- PAYSTACK_SECRET_KEY (secret; use the LIVE key only when ready to take real payments)
- ENVIRONMENT = test until all test cases pass; change to live only for launch
- SUPABASE_ASSESSMENTS_TABLE = ftriva_assessments (if this is your actual table name)

Paystack recurring plan codes (create/configure one plan per membership):
- PAYSTACK_PLAN_ESSENTIAL
- PAYSTACK_PLAN_PLUS
- PAYSTACK_PLAN_ELITE
Each plan must match R249, R399 and R599 monthly respectively. No membership Black Friday discount is applied.

EMAIL NOTIFICATIONS:
- Onboard ftriva.com in Cloudflare Email Service > Email Sending.
- Complete the DNS records Cloudflare provides for SPF, DKIM and DMARC.
- The Worker uses the restricted EMAIL binding in wrangler.jsonc. It may send only from notifications@ftriva.com to ftrivafitness@gmail.com.
- Notifications are generic sign-up alerts only. Customer names, contact details, payment references and assessment answers are not included.
- Email failures never block a successful payment or Founding 10 claim.
- Confirm Paystack sends charge.success and subscription.create events to the configured Worker webhook.

SUPABASE SETUP:
1. Review FOUNDER_10_SETUP.sql.
2. Run it in the Supabase SQL Editor for the SAME project used by FTRIVA. It is additive and creates only the Founding 10 claims table and RPC function.
3. Confirm the existing ftriva_assessments table has columns: payment_reference, package_type, customer_email, assessment_data (json/jsonb), requested_start_date, status, submitted_at. Do not create a duplicate table without checking your current schema.

IMPORTANT:
- Website prices in this build: START R199 (was R299); PROGRESS R399 (was R549); PERFORMANCE R299 (was R399); DIGITAL R49 (was R149). Memberships stay at R249/R399/R599 per month.
- These once-off promotional prices reflect the proposed sale prices selected in the planning conversation; verify before live launch.
- Founding 10 is limited to one free qualifying once-off programme per email. Claim limit is enforced in Supabase under a transaction lock, not by a browser counter.
- The assessment is saved in Supabase. WhatsApp receives a short notification only, not the customer's sensitive assessment answers.
- This package does not configure your secrets, run SQL, connect your Paystack account, or perform a live charge. Those steps require your account-side action and testing.
